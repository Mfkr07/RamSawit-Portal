Kebijakan Privasi

Terakhir diperbarui: Oktober 2026

Data yang kami kumpulkan

RamSawit menyimpan data operasional yang kamu masukkan: transaksi pembelian, data penjual, pengiriman ke pabrik, pengeluaran, dan saldo dana. Data akun (email & peran) disimpan untuk autentikasi.

Penyimpanan lokal & cloud

Data tersimpan di database lokal perangkat (offline-first) dan tersinkron ke cloud saat online. Database cloud dilindungi Row Level Security — setiap akun hanya mengakses data sesuai perannya.

Data yang tidak kami kumpulkan

Kami tidak melacak lokasi, tidak membaca kontak, dan tidak menjual data ke pihak ketiga. Fitur AI hanya memproses data operasionalmu untuk menghasilkan insight.

Hak kamu

Kamu dapat meminta ekspor atau penghapusan datamu kapan saja melalui kontak pengembang. Transaksi yang dibatalkan tercatat sebagai void demi integritas audit.
