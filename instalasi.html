Panduan

Panduan Pemasangan & Menjalankan Aplikasi

Langkah mudah memasang di ponsel Android atau menjalankan di komputer Windows.

Platform Mobile

Untuk Ponsel Android (APK)

01

Unduh file APK Resmi

Ketuk tombol unduh di bawah ini. File paket rilis mandiri (v2.5.4) akan tersimpan di folder Unduhan perangkat Anda.

Unduh APK ARM64 v2.5.9 (~27.1 MB)
02

Izinkan sumber tidak dikenal

Buka Pengaturan → Keamanan → aktifkan “Instal aplikasi yang tidak dikenal” untuk browser/Chrome. Cukup sekali saja.

03

Buka & pasang

Ketuk file APK yang sudah diunduh, lalu ketuk “Instal”. Setelah selesai, ikon RamSawit muncul di layar utama.

Tips Android: jika muncul peringatan Play Protect, pilih “Tetap instal” — file APK ini langsung dari pengembang resmi RamSawit.

Platform Desktop

Untuk Komputer Windows (Desktop 64-bit)

01

Unduh Paket Aplikasi Windows

Unduh paket RamSawit_V.2.5.4_Windows.zip (~15.9 MB) yang sudah dilengkapi runtime Visual C++ dan database SQLite.

Unduh Paket Windows (.ZIP 15.9 MB)
02

Ekstrak Berkas ZIP

Klik kanan pada file ZIP yang telah diunduh, lalu pilih "Extract All". Anda akan mendapatkan folder mandiri yang berisi seluruh komponen aplikasi.

03

Buka & Siap Pakai

Jalankan file RamSawit.exe di dalam folder. Aplikasi RamSawit langsung siap dipakai tanpa perlu instalasi rumit.

Tips Windows: jika muncul dialog perlindungan Windows SmartScreen saat pertama kali dibuka, klik “More info” lalu pilih “Run anyway”.
